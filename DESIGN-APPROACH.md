# Design approach

Nirvan '26 uses a kinetic editorial direction: acid green on ink, mono labels, a strong display scale, and real event posters as the visual anchors. The layout is deliberately closer to a festival program than a marketing landing page, with the event arena and schedule exposed early for quick scanning.

The experience is responsive, keyboard-friendly for the main controls, and uses the event data as the single source of truth for filters and detail modals.

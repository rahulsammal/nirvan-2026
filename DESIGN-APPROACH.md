# Design approach

Nirvan '26 uses a kinetic editorial direction: acid green on ink, mono labels, a strong display scale, and real event posters as the visual anchors. The layout is deliberately closer to a festival program than a marketing landing page, with the event arena and schedule exposed early for quick scanning.

The experience is responsive, keyboard-friendly for the main controls, and uses a small vanilla JavaScript data layer for filters, event details, registration, countdown, schedule, speakers, and the gallery lightbox. The site has no framework or build dependency: `index.html`, `style.css`, and `script.js` can be opened directly or deployed to any static host.
